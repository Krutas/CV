# CV

Online resume of **Matas Skirkevičius**, CNC programmer and mechanical engineer from Kaunas, Lithuania.

- **Website:** https://krutas.github.io/CV/
- **PDF:** [Matas-Skirkevicius-CV.pdf](Matas-Skirkevicius-CV.pdf)

## Files

| File | What it is |
|---|---|
| `index.html` | Animated CV website (single file, no build step) |
| `print.html` | A4 print layout the PDF is made from |
| `Matas-Skirkevicius-CV.pdf` | Two-page PDF CV |
| `resume-data.md` | All CV content in plain text |

To rebuild the PDF, open `print.html` in Chrome or Edge and print to PDF (A4, no margins, background graphics on).
